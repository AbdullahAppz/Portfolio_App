# 📱 Professional Portfolio Mobile Application

A modern and responsive Portfolio Mobile Application developed using **Flutter** and **Firebase**. This application allows users to showcase their professional profile, technical skills, projects, and contact information through an intuitive mobile interface.

---

## 📌 Project Overview
The Professional Portfolio Mobile Application was developed as the final project for the **Codiora 8-Week Mobile App Development Internship**.

The application demonstrates modern mobile development practices including Firebase integration, state management, responsive UI design, offline caching, dark mode, search functionality, and professional user experience.

## 🚀 Installation
1. Clone Repository
2. Move to Project
3. Install Packages
4. Configure Firebase
    - Create a Firebase Project
    - Enable Authentication
    - Create Firestore Database
    - Add Android Application
    - Download `google-services.json`
5. Run Application
